# 처음 사용하는 배차 시스템 설명서

앱 상단의 **사용설명서**에서도 업무 흐름을 확인할 수 있습니다.

상단 메뉴는 **사용설명서 / 배차 신청 / 배차 확정 / 설정**입니다. 배차 신청에서 납품과 경로·지도를 함께 확인한 다음 **다음: 배차 확정**을 누릅니다. 배차 확정 화면은 왼쪽 확정 대기와 오른쪽 확정·완료 내역으로 나뉩니다. 배차는 담당자가 직접 확정해야 합니다.

업무 흐름에서 납품 등록은 작업 단계 이름이고, 추천 확인·배차 확정·납품 완료는 각각 해당 상태의 건수입니다. 전체 등록 건수는 날짜 옆 **전체**에서 확인합니다.

## 매일 하는 일

1. **배차 신청**에서 납품일을 선택하고 납품 일정을 등록합니다.
2. 같은 화면의 **경로 · 지도**에서 차량, 편도·왕복 경로와 예상 비용을 확인합니다.
3. **배차 확정** 화면에서 확정 대기 건을 확인하고 **배차 확정**을 누릅니다.
4. 납품이 끝나면 일정 카드의 **완료 처리**를 누릅니다.

완료 처리는 현재 배차 확정 상태인 납품만 가능하며, 완료 취소는 현재 완료 상태인 납품만 가능합니다. 다른 사람이 먼저 처리했거나 삭제해 상태가 바뀌었다는 안내가 나오면 화면의 최신 내역을 확인하세요.

새 납품 등록의 차량 선택에서 **용차** 또는 **택배**를 선택할 수 있습니다. 등록 후 카드에서도 운송 수단을 변경할 수 있습니다. 용차·택배는 자사 차량의 잔여 적재량과 차량 경로에 포함되지 않습니다.

**배차 확정** 화면의 카드에서 운송 금액을 입력하고 저장합니다. 금액은 납품 품목과 선택한 운송 수단에 연결되어 서버에 저장됩니다. 빈 값으로 저장하면 입력이 지워지며, 0원과 미입력은 구분됩니다. 묶음 카드의 **품목별 운송 금액**에서 각각 입력할 수 있습니다. 여러 품목을 한 번에 청구받은 금액이라면 한 품목에만 입력해 중복 기록을 피하세요. 운송 수단을 바꾸면 그 수단에 입력한 금액이 표시됩니다. 이 금액은 현재 엑셀 내보내기나 AI 시뮬레이션 비용에 자동 반영되지 않습니다. 용차·택배 건은 기존 자사 차량 합차 기능에서 자동으로 자사 차량으로 바뀌지 않도록 합차가 제한됩니다. 같은 거래처 여러 품목은 새 납품 등록에서 함께 등록하세요.

## 1. 납품 일정 등록

1. 상단 **배차 신청**을 선택하고 납품일을 확인합니다.
2. 오른쪽 위 **새 납품 등록**을 누릅니다.
3. 날짜, 거래처, 지역, 품명과 수량을 확인하고 필요한 값을 입력합니다. 수량 단위는 박스 또는 PLT를 고릅니다.
4. 차량을 자동 추천으로 두거나 직접 선택한 뒤 **등록**을 누릅니다.
5. 새 카드가 **추천 확인**에 나타나면 차량과 카드의 확인 사항을 살펴봅니다. 필요하면 차량 선택이나 **수정**으로 고칩니다.
6. 차량과 경로를 확인한 뒤 **다음: 배차 확정**을 누르고 확정 화면에서 **배차 확정**을 누릅니다. 납품 후에는 **완료 처리**를 누릅니다.

새 박스 납품은 추가 PLT를 0으로 계산하고 적재 방식은 확인 필요로 표시합니다. **배차 신청** 또는 **배차 확정** 카드의 **박스 적재**에서 기존 PLT 합적, 별도 박스 적재 또는 별도 PLT 사용을 선택하고, 별도 PLT를 쓰면 수량을 입력하세요. 합적 대상은 메모할 수 있으나 다른 파렛트와 자동으로 연결되지는 않습니다. 묶음 카드도 품목별로 설정할 수 있습니다. 기존 박스 납품은 기존 PLT 값을 유지하므로 실제 적재 방식을 확인해 저장하세요. 박스 중량은 기준표에 있으면 박스 수를 곱해 합산하고, 없으면 미확인으로 표시합니다. 0 PLT는 실제 공간이 확보되었다는 뜻이 아니며 합적 공간과 고정 가능 여부는 담당자가 확인해야 합니다. 추천은 최종 배차 결정을 대신하지 않습니다.

품명 칸을 다시 누르거나 화살표를 누르면 전체 목록이 열립니다. 검색하거나 다른 품명을 선택해 바로 교체할 수 있고, × 버튼으로 지울 수 있습니다. 추가 품목도 같은 방식입니다. 자동 추천된 거래처·지역은 품명에 따라 바뀔 수 있지만 직접 선택한 값은 유지됩니다. 등록 후에는 카드에서 품명을 수정할 수 있습니다.

한 거래처에 여러 품목을 납품한다면 **+ 품목 추가**를 누르고 각 품명과 수량·단위를 입력합니다. 품목이 한 카드에 묶여 표시되며 차량과 합계 적재량을 확인할 수 있습니다. 추가한 줄은 등록 전에 **품목 삭제**로 지울 수 있습니다.

엑셀에서 새로 가져온 박스 품목도 추가 0 PLT와 적재 방식 확인 필요로 시작합니다. 박스 수나 무게만으로 별도 파렛트가 있다고 확정하지 않습니다. 기존에 저장된 납품의 PLT 값은 그대로 유지되므로 실제 적재 방식을 확인한 뒤 수정하세요.

오른쪽 **잔여 PLT · 차량**에서 차량별 박스 수, 사용량과 잔여 적재량을 볼 수 있습니다. 그 아래에 **배송 금액 · 금수레**가 있습니다. PLT는 파렛트 단위입니다.

차량별 중량 합계와 차량 1대의 최대 중량도 확인할 수 있습니다. 합계가 1대 기준을 넘으면 운행별 분할이 필요한지 확인하세요. **미확인** 또는 **추정** 건수가 있으면 실제 중량을 확인해야 합니다. 여러 운행의 합계가 표시될 수 있어 경고가 곧 실제 과적을 뜻하지는 않습니다.

### 여러 건을 한 번에 배차 확정하기

1. 각 카드의 체크박스 또는 **전체 선택**으로 납품을 선택합니다.
2. 차량과 각 카드의 확인 사항을 검토한 뒤 **선택 배차 확정**을 누르고 확인합니다.
3. 선택한 건 중 **추천 확인** 상태만 확정됩니다. 이미 확정되거나 완료된 건은 바뀌지 않으며, 실제 확정된 건수는 화면에 표시됩니다.

## 2. 여러 납품을 합차하기

같은 날 여러 건을 한 차로 운행할 때 사용합니다.

1. 보드에서 묶을 카드의 체크박스를 2건 이상 선택합니다.
2. 위쪽 **합차**를 누르고 확인합니다.
3. 같은 상태의 품목이 한 카드로 묶여 보이고 차량이 함께 맞춰집니다. 적재량과 방문 순서를 확인하세요.
4. 묶음을 풀려면 카드의 **묶음 해제**를 누릅니다. 차량 배정은 유지됩니다.

합차 그룹 중 한 카드의 차량을 바꾸면 그룹 전체에 반영됩니다. 완료되거나 취소된 일정은 합차할 수 없습니다.

묶음 카드의 **품목별 수정**으로 각 품목을 고칠 수 있습니다. 배차 확정·완료 처리·삭제는 해당 카드에 표시된 품목 전체에 적용됩니다. 같은 묶음에 서로 다른 상태가 있으면 상태별 칸에 나뉘어 표시됩니다.

## 3. 경로와 방문 순서 확인

1. **배차 신청**에서 납품일을 고르고 신청 내역 아래의 **지도 보기**를 눌러 **경로 · 지도** 영역으로 이동합니다.
2. 오른쪽 **운행 구간**에서 **편도** 또는 **왕복**을 선택합니다. 편도는 회사에서 마지막 납품지까지, 왕복은 납품지를 거쳐 회사로 돌아오는 구간입니다.
3. **경로 계산**을 누릅니다. 차량별 지도 선과 거리, 시간, 예상 통행료가 표시됩니다. 운행 구간이나 방문 순서를 바꾼 뒤에는 **경로 새로고침**을 누릅니다.
4. 한 차량의 방문 순서를 바꾸려면 목록 항목을 위아래로 드래그합니다. **추천 순서**를 누르거나, 현장 제약을 문장으로 입력하고 **제약 해석**을 눌러 조정할 수도 있습니다.
5. 같은 방문 순서에서 다른 길을 비교하려면 해당 차량의 **다른 경로**를 누릅니다. 추천, 최단 시간, 최단 거리, 큰길 우선 중 하나를 고르면 지도와 비용이 바뀝니다.
6. 차량별 **출발시간**을 입력하면 방문 목록에 업체별 예상 도착시간이 표시됩니다. 조회 시점 교통 기준이며 하차·대기시간은 포함하지 않습니다. 출발시간은 화면을 나가면 초기화됩니다.

같은 묶음에서 업체·지역·차량·좌표가 같은 품목은 지도와 방문 목록에서 한 방문지로 표시됩니다. 방문 목록의 **품목 보기**를 누르면 품명과 수량을 펼쳐 볼 수 있습니다. 서로 다른 업체는 합차하더라도 각각의 방문지로 남습니다. 방문 순서를 옮기면 해당 방문지의 묶인 품목이 함께 이동합니다.

지도는 기본적으로 미확정 배차 신청을 표시합니다. 여러 건을 선택해 한 번에 확정하면 하나의 확정 배차 묶음으로 저장됩니다. **표시할 배차**에서 묶음을 선택하면 해당 납품만 표시되고, **경로 계산**을 누르면 1호차·2호차 등 각 차량의 경로가 따로 나타납니다. 기능 도입 전에 확정된 건은 당시 묶음 정보가 없어 **이전 확정 배차**에 함께 표시됩니다.

**확정 배차 전체**를 선택하면 선택한 날짜의 확정·완료 납품과 각 묶음에 저장된 경로를 함께 봅니다. 서로 다른 묶음을 하나의 운행으로 계산하지 않습니다. 저장된 경로가 없거나 일정이 바뀐 묶음은 **경로 확인**에서 묶음을 열어 다시 계산하세요. 지도 위 **현재 표시**에는 범위와 건수가 표시됩니다. 용차·택배는 납품지 마커에 나타날 수 있지만 자사 차량 경로에서는 제외됩니다. 카카오 조회 실패로 저장된 직선 근사 경로일 수 있으므로 상세 화면을 확인하세요.

확정 묶음의 납품이 모두 삭제되거나 취소되면 지도 선택 목록에서 숨겨집니다. 일부 납품이 남았거나 완료된 납품이 있는 묶음은 계속 표시됩니다.

지도 아래 **AI 배차 시뮬레이션**에서 일정표 엑셀과 원하는 납품일을 선택합니다. 선택한 날짜와 월별 시트가 엑셀에 있어야 합니다. AI는 기존 자사 차량 납품을 유지하면서 용차·택배 물량을 자사 차량에 합치는 안을 제안하고 차량 간 이동도 검토합니다. 자사 차량에 옮기지 않은 용차 품목은 AI가 운행별로 묶고, 그 묶음 수가 제안 용차 횟수가 됩니다. 같은 거래처·지역뿐 아니라 같은 날 인접 권역의 다른 거래처도 한 용차 다중 경유로 묶을 수 있습니다. 기존 계획의 방문 순서는 엑셀 행 순서로 가정합니다. 용차비는 **운행 단위**로 입력합니다. 편도(납품 또는 회수)와 왕복(납품·경유 후 P박스 회수 패키지)을 고르고, 필요하면 기존 운행을 묶어 한 용차로 처리하거나 회수 편도를 추가합니다. 운행·운임은 파일·날짜별로 해당 브라우저에 저장되며, 미입력 운행은 1회 20만 원으로 가정합니다. AI 후보 선택에는 여전히 1회 20만 원 가정이 사용됩니다. 차량 톤수·적재량과 납품 기한 등이 미확인이라 용차 묶음과 AI 제안은 현장 검토가 필요합니다. 택배비는 박스당 7,000원 또는 파렛트당 50,000원으로 계산하며 출고 방식과 수량 확인이 필요합니다. 인건비 등은 제외되어 전체 실제 비용이 아닙니다. 시뮬레이션은 실제 배차를 변경하지 않습니다.

1. 엑셀 파일과 납품일을 선택한 뒤 **분석 제외 품목 선택**에서 샘플 등 제외할 행을 체크하고 **배차안 불러오기 / 만들기**를 누릅니다. 제외 선택은 기존안과 AI안 모두에 적용되며 원본 엑셀은 바뀌지 않습니다. 그래프는 자사 차량의 운전 시간에 차량당 점심 60분과 거래처·주소별 하차 40분(현담산업 180분)을 더한 합계입니다. 용차·택배와 기타 대기 시간은 제외합니다. 그래프 아래 **차량별 경로·적재 품목 보기**에서 납품 순서, 품목과 PLT를 확인하고, **분석 리포트 보기**에서 AI 선택 과정과 계산 근거를 확인합니다. 미확인 PLT는 합계에 포함되지 않습니다.
2. **예상 비용 비교**에서 기존 계획·AI 제안과 차이를 보고, **용차 운행·운임 조정**을 펼쳐 기존 계획과 AI 제안을 나란히 확인합니다. 운행마다 편도/왕복과 운임을 입력하고, 기존 계획에서는 선택 운행 묶기·분리·회수 편도 추가를 사용할 수 있습니다. AI 용차 횟수는 제안 묶음에서 계산합니다. 차량·외부 운송 품목은 **분석 리포트 보기**에서 확인합니다.

   그래프 아래 **택배 품목**에서 기존안과 AI안의 택배 출고 방식을 확인합니다. 박스당 7,000원, 파렛트당 50,000원을 예상 비용에 더합니다. 출고 방식이나 수량이 미확인이면 직접 입력할 수 있습니다. 택배비가 미확인일 때는 양쪽 비용 그래프에서 택배비를 제외하며, 모든 수량을 확인하면 택배비가 포함됩니다. 합적된 다른 행은 실제 PLT를 0으로 입력할 수 있습니다. 택배비는 AI 후보 선택에는 반영되지 않습니다.

   기존 계획이나 AI 제안에서 **용차 운행 추가**로 기존 품목에 대한 추가 운행을 시험할 수 있습니다. 이는 기존 품목의 배정을 바꾸지 않고 별도 비용만 더하므로 기존 운행과 중복 여부를 확인하세요.

   잘못 추가한 회수 운행은 **회수 운행 삭제**로 지울 수 있습니다. 기존 납품 용차는 **비용에서 제외**하거나 다시 포함할 수 있습니다. 제외해도 납품과 AI 배차는 바뀌지 않으므로 각 안을 같은 조건으로 비교할 수 없습니다.

   AI 제안 용차는 목적지별로 분리하거나 여러 운행을 선택해 묶고, 회수 편도를 추가·삭제할 수 있습니다. 이는 사용자가 조정한 참고안이며 실제 경유·적재 가능 여부와 운임을 확인해야 합니다. 변경한 운행의 운임을 입력하지 않으면 1회 20만 원으로 가정합니다. **AI 원래 묶음으로 되돌리기** 또는 AI 배차안 다시 만들기를 사용하면 AI 용차 운임 입력값도 초기화됩니다.
3. 주소·경로·운행 횟수 또는 비용을 확인할 수 없으면 전체 비교 금액이 표시되지 않을 수 있습니다. AI 응답이 실패하거나 품목 검증에 실패한 경우 다시 실행합니다. AI가 기존과 같은 안을 제안할 수도 있으며, 그 결과만으로 AI의 효과나 실제 절감을 확정할 수 없습니다.

**현재 안의 경로 새로고침**은 배차안을 유지하고 카카오 경로만 새로 조회합니다. **AI 배차안 다시 만들기**는 새 후보를 생성합니다. 알려진 적재 한도 초과 후보는 제외하고, 비교 가능한 후보는 경유비·통행료·용차비를 기준으로 평가합니다. 미확인 적재량·택배비·인건비 등이 있어 최적해나 실제 운행 가능성을 보장하지 않습니다. 기존에 저장되지 않은 과거 결과는 복원할 수 없습니다.

시뮬레이션 후 **품목별 박스 적재 방식 설정**에서 확인 필요, 기존 PLT에 합적, 별도 박스 적재, 별도 PLT 필요 중 고르고 다시 실행합니다. 별도 설정이 없는 품목은 제품 기준표의 1PLT당 박스 수로 PLT를 자동 추정합니다. 품명이나 기준이 맞지 않거나 박스 수가 없으면 확인 필요로 표시합니다. 이 수치는 실제 적재 방식이 확정된 것이 아닙니다. 합적·별도 박스는 추가 PLT를 계산하지 않지만 실제 공간·고정 가능 여부는 담당자가 확인해야 합니다. 박스 중량은 알 수 있으면 계속 합산합니다. 적재 설정·경유 가격·용차 운행(편도/왕복·묶음·운임)은 이 브라우저에 저장되며 엑셀을 다시 선택하면 복원됩니다.

마지막 경로는 날짜와 선택한 배차별로 저장되어 다른 화면에 다녀오거나 브라우저를 새로고침해도 복원됩니다. 브라우저 새로고침이나 화면 이동만으로 카카오 경로가 자동으로 다시 계산되지는 않습니다. 최신 교통 상황을 보려면 **경로 새로고침**을 누르세요. 일정 내용이 바뀌면 이전 결과 경고가 나오고, 표시할 납품 목록이 달라지면 이전 경로를 숨긴 뒤 다시 계산하도록 안내합니다. 기존 날짜 전체 경로는 표시 기준이 달라 처음에는 다시 계산해야 합니다. 지도에 없는 납품지는 주소·좌표와 차량 배정을 확인합니다. 길찾기에 실패하면 직선거리 근사 경로가 표시될 수 있습니다.

## 4. 통행료와 경유비

경로 계산 후 차량 카드에서 **예상 통행료**와 **예상 경유비**를 볼 수 있습니다.

- 경유 가격은 오피넷 전국 평균을 자동으로 불러옵니다. 가격을 직접 입력하거나 다시 전국 평균을 적용할 수 있습니다. 조회가 실패하면 직접 입력하세요.
- 1호차와 2호차의 연비는 임시 추정치입니다. 스타리아는 특정 디젤 차량 사양의 공인연비를 참고한 값입니다. 실제 차량에 맞게 연비를 수정할 수 있습니다.
- 경유비는 선택한 경로의 거리 ÷ 연비 × 리터당 경유 가격입니다. 실제 적재량, 운전 조건, 주유소 가격에 따라 달라집니다.
- 통행료는 톤수를 기준으로 잠정 차종 분류를 적용합니다. 실제 차종이나 요금은 별도 확인하세요. 조회 실패 또는 여러 구간으로 나뉜 경로는 **확인 불가**로 표시될 수 있습니다.
- 직접 입력한 경유 가격과 연비는 화면을 다시 열면 초기화됩니다.

## 5. 금수레 용차 운임

**배차 신청** 오른쪽의 **배송 금액 · 금수레**에서 금수레 운임표를 확인합니다.

1. 도착지와 차량 톤수(1톤~, 3.5톤, 5톤)를 선택합니다.
2. 예상 운임을 확인하고, 업체에 확인한 금액이 있으면 실제 청구액 메모에 입력합니다.

차량 용차 운임은 범위로 표시됩니다. 실제 청구액 메모는 해당 브라우저에 날짜와 선택 조건별로 저장되며 개별 배송 정산 기록은 아닙니다. 표에 없는 지역이나 여러 납품지를 경유하는 운임은 업체에 확인하세요.

## 6. 엑셀과 설정

- 기존 일정 엑셀을 불러올 때는 **설정 → 처음 가져오기**를 사용합니다. 다시 가져오기 전 화면의 안내를 확인하세요.
- **이 달 내보내기**는 선택한 날짜가 속한 달의 일정을, **전체 내보내기**는 전체 일정을 엑셀로 내려받습니다.
- **설정 → 차량**에서는 차량 이름과 적재 기준을, **설정 → 지역**에서는 지역 분류와 선호 차량을 확인·수정합니다. 추천 결과에 영향을 줄 수 있습니다.

## 7. 문제가 생겼을 때

- 일정이 안 보이면 납품일을 확인합니다.
- 지도에 납품지가 없으면 해당 일정의 거래처·지역과 주소를 확인합니다.
- 경로가 직선으로만 보이면 카카오 길찾기 연결을 확인합니다.
- 오피넷 가격이 표시되지 않으면 경유 가격을 직접 입력하고 관리자에게 문의합니다.
- 통행료가 **확인 불가**면 0원이라는 뜻이 아닙니다. 별도로 확인합니다.
