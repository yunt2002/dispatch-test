# 네오마그네틱 배차 — 사용설명서

> 처음 사용하는 분은 최신 화면과 운임 기능을 반영한 [처음 사용하는 배차 설명서](./처음_사용하는_배차_설명서.md)를 먼저 보세요. 아래 내용은 이전 안내입니다.

납품 일정을 넣고, 차를 추천받고, 엑셀로 주고받는 흐름을 확인하기 위한 프로토타입입니다.  
**확정된 운영 시스템이나 ERP가 아닙니다.** 제품·거래처 마스터를 키우지 않습니다.

현재 기능은 시연과 현업 검증을 위한 것입니다. 실제 업무에 계속 사용할지는 기존 방식 대비 효과, 현장 규칙, 유지보수 주체를 확인한 뒤 결정합니다.

브라우저 탭 제목은 `네오마그네틱 배차`입니다.  
설명·기획은 [기획서.md](./기획서.md) 를 같이 보면 됩니다.

---

## 1. 한 줄

**지역 + 수량(+ 품명) → 차량 추천 → 그날 일정에 쌓기**

엑셀은 **처음 가져오기**와 **원래 납품예상 일정표 양식으로 내보내기**만 씁니다.  
프로토타입에서 배차 흐름을 확인할 때는 홈(일정 · 배차)을 사용합니다.

추천은 **강제하지 않습니다.** 목록에서 다른 차로 바꿀 수 있습니다.

### 하지 않는 것

- 표에 없는 품목을 임의로 박스÷숫자 = PLT로 환산
- 용차·택배를 자사 차로 강제
- 거래처/제품 ERP 관리

### 합차 (가능)

홈 보드에서 카드 **체크 → 합차**로 여러 납품을 **한 대·한 운행**으로 묶을 수 있습니다.  
품목이 한 카드에 표시되고 `합차 XXXX` 뱃지가 붙습니다. **묶음 해제**로 풀 수 있습니다.

## 2. 화면

| 메뉴 | 용도 |
| --- | --- |
| **일정 · 배차** | 매일 쓰는 홈. 등록, 추천, 수정, 완료, 내보내기 |
| **설정 → 처음 가져오기** | 기존 납품관리 엑셀을 일정으로 넣기 |
| **설정 → 차량** | 1호·2호·3호·스타리아의 톤·PLT·지역 용도 |
| **설정 → 지역** | 위치 이름 → 수도권/지방 |

홈 오른쪽 위에는 **이 달 내보내기** / **전체 내보내기**와 **새 납품 등록**이 있습니다.  
가져오기는 설정에만 있습니다.

예전 출하·배차·제품·거래처 화면은 막아 두었고, 열면 홈으로 갑니다.

## 3. 기능 확인 방법

### 3-1. 엑셀이 있을 때 (처음 한 번)

1. **설정 → 처음 가져오기**
2. 쓰던 `납품예상 일정표 및 납품관리` 엑셀(.xlsx)을 올린다.
3. 월 시트명(예: `26년 09월`)은 비워도 된다. 비우면 최근 월 시트를 찾는다.
4. 가져오기가 끝나면 홈에 날짜별 일정이 생긴다.

다시 가져오면 **엑셀에서 온 일정만** 그 파일 내용으로 바뀝니다.  
홈에서 직접 넣은 일정은 남습니다. 건수가 있으면 확인 창이 뜹니다.

### 3-2. 날짜 보기

홈 위쪽에 **납품일**이 있습니다.

- 왼쪽 목록: 일정이 있는 날. `9/16(수)`처럼 보입니다.
- 오른쪽 날짜 칸: **빈 날**(내일 등)로 바로 갑니다.

목록과 등록 칸의 날짜는 같이 맞춰집니다.

### 3-3. 일정 등록

홈 오른쪽 위 **새 납품 등록**을 눌러 입력합니다.

같은 거래처의 여러 품목은 **+ 품목 추가**로 각 품명과 수량·단위를 입력해 한 번에 등록할 수 있습니다. 품목은 한 카드에 묶여 표시되며, 차량과 합계 수량을 확인합니다.

| 칸 | 필수 | 설명 |
| --- | --- | --- |
| 납품일 | 예 | 보고 있는 날이 기본값 |
| 지역(위치) | 조건부 | 거래처·품명으로 추천될 수 있으며, 추천되지 않으면 선택 |
| 수량 | 예 | 기본 **박스**. 이미 PLT를 알면 단위를 PLT로 |
| 품명 | 아니오 | 예: `DIC SBW`, `GEN2`. 적재표에 있으면 박스를 PLT로 바꿈 |
| 거래처 | 아니오 | 예: 만도브로제 |

**등록**을 누르면 추천 확인 칸에 카드가 생깁니다. 품명으로 자동 추천된 거래처·지역은 품명을 바꾸면 다시 채워질 수 있으니 등록 전에 확인하세요. 직접 선택한 값도 필요하면 바꾸세요.

품명을 안 넣으면 박스→PLT 환산은 하지 않고, 지역 기준으로만 추천합니다.

### 3-4. 그날 목록

그날 일정이 **추천 확인 → 배차 확정 → 납품 완료** 상태별 카드로 보입니다.

각 행에서 할 수 있는 일:

| 버튼 | 동작 |
| --- | --- |
| 차량 드롭다운 | 추천과 다른 차로 바꿈. PLT가 있으면 대수(×2 등)를 다시 계산 |
| **수정** | 지역·거래처·품명·수량. 지역/수량/품명이 바뀌면 추천을 다시 돌림 |
| **배차 확정** | 추천 확인 건을 확정 칸으로 이동 |
| **완료 처리** | 확정된 건을 납품 완료로 표시 |
| **완료 취소** | 다시 배차 확정으로 |
| **삭제** | 확인 후 삭제 |
| **합차 / 묶음 해제** | 체크한 2건 이상을 한 차로 묶거나 해제 |

추천과 다른 차를 고르면 행에 `추천 2호차`처럼 원래 추천이 남습니다.  
합차 그룹에서는 한 건의 차량을 바꿔도 그룹 전체가 같이 바뀝니다.
묶음 카드의 **품목별 수정**에서 항목을 수정할 수 있으며, 확정·완료·삭제는 해당 카드의 전체 품목에 적용됩니다. 상태가 다르면 상태별 칸에 나뉘어 표시됩니다.

보드 위 **선택 삭제 / 이 날짜 전부 삭제**로 여러 건을 지울 수 있습니다.  
보드 위 **선택 배차 확정**은 체크한 건 중 추천 확인 상태만 확정합니다. 차량과 확인 사항을 검토한 뒤 버튼과 확인 창을 누르세요. 확정·완료된 건은 바뀌지 않고 실제 처리 건수가 표시됩니다.

오른쪽 **잔여 PLT · 차량**에는 호차별 **박스 수·PLT·잔여**가 나오고, 그 아래 **배송 금액 · 금수레**에서는 도착지와 1톤~, 3.5톤, 5톤 용차 운임을 확인합니다. 실제 청구액 메모는 해당 브라우저에 날짜·선택 조건별로 저장됩니다.

차량별 중량 합계도 1대 기준 최대 중량과 함께 표시합니다. 기준 초과 시 운행별 분할을 확인하고, 중량 미확인 또는 추정 건이 있다면 실제 값을 확인하세요.

수량에 `64 박스 · 2 PLT`처럼 보이면, 적재표로 환산된 것입니다.

### 3-5. 엑셀로 다시 빼기

홈에서:

- **이 달 내보내기** — 고른 날짜가 속한 달만. 시트 이름 예: `26년 09월`
- **전체 내보내기** — 일정이 있는 달을 월별 시트로 전부. 원본 엑셀처럼 여러 월이 한 파일에 들어갑니다.

날짜는 `9/16(수)` 형태로 나갑니다.

### 3-6. 경로 보존과 예상 도착시간

**경로 · 지도**에서 마지막으로 계산한 경로는 날짜별로 저장됩니다. 화면을 이동하거나 브라우저를 새로고침하면 저장된 결과를 복원하며, 최신 경로는 **경로 새로고침** 버튼을 눌러 조회합니다. 일정·차량·방문 순서 또는 편도·왕복이 바뀌면 다시 계산하세요.

차량별 출발시간을 입력하면 방문 목록에 업체별 예상 도착시간이 나타납니다. 조회 당시의 구간별 이동시간을 더한 값으로, 하차·대기시간은 포함하지 않습니다. 출발시간은 화면을 나가면 초기화됩니다. 구간별 이동시간이 없는 기존 경로는 다시 조회해야 합니다.

## 4. 차는 어떻게 고르는가

1. **지역**  
   수도권 → 2호차, 지방 → 1호차.  
   목록에 없는 위치는 미분류로 두고, 차는 추천하되 지역 목록에 자동 저장되지 않습니다.
2. **PLT를 알 때**  
   차량 한도(아래 표)로 대수를 계산합니다. 예: 2 PLT를 스타리아(1 PLT)로 바꾸면 `×2`.
3. **박스만 있고 품명이 표에 있을 때**  
   입수(1PLT당 박스)로 PLT를 구한 뒤 2번과 같습니다.  
   예: DIC SBW 내수 56박스 ÷ 28 = 2 PLT.  
   엑셀에서 가져온 행이거나, 홈에서 품명을 넣은 행입니다.
4. **박스만 있고 품명이 없거나 표에 없을 때**  
   PLT를 만들지 않습니다. 지역 추천만 합니다.

### 차량 (잠정)

**설정 → 차량**에서 바꿀 수 있습니다. 적재함 치수는 기록만 하고, 추천은 아직 PLT 대수 기준입니다.

| 차량 | 톤 | 차체 | 적재함 | 최대 PLT | 기본 용도 |
| --- | --- | --- | --- | --- | --- |
| 1호차 | 4.0t | 윙바디 | 5,200×2,300 | 8 | 지방·고정 루트 |
| 2호차 | 3.5t | 윙바디 | 5,000×2,150 | 8 | 수도권·유동 |
| 3호차 | 2.5t | — | (미정) | 2 | 긴급 |
| 스타리아 | 1.0t | — | (미정) | 1 | 긴급·소량 |

중량은 제품 정리 시트의 **BOX별 중량(g)×박스 수**를 우선하고, PLT만 알 때는 시트 **PLT 무게**를 씁니다.  
잠정 기본값은 **600kg/PLT**입니다. 홈 오른쪽에서 차량별 **박스·사용/잔여 PLT**를 봅니다.  
낱개(TMED2·GEN1·EC PUMP 등)는 PLT 환산 없이 자리 1칸·박스 중량으로 안내합니다.

### 고정 권역 (1호 기준)

- **전라도**: 광주(BMC), 코아오토모티브, 한온 등 → 1호
- **경상도**: 대구·창원·김해·울주·부산항 등 → 1호
- **공통/유동**: 충청·세종(코아비스 등) → 잔여 PLT·동선으로 1호 또는 2호

설정 화면에서 긴급 배차용(3호·스타리아), 소량·박스 우선(스타리아)을 켜 둘 수 있습니다.

## 5. 박스 → PLT 표

현장 적재표입니다. **입수 = 1PLT에 들어가는 박스 수.**

P 접이식박스는 P 박스로 봅니다. (EC PUMP)

**낱개**인 제품군은 PLT로 바꾸지 않습니다.

| 제품군 | 박스 | 입수 | 파렛트 |
| --- | --- | --- | --- |
| IDB GEN2 | P 박스 | 40 | 1200×1000 |
| EPS | P 박스 | 42 | 1200×1000 |
| 3.2 ROTOR | P 박스 | 60 | 1100×1100 |
| DIC SBW 내수 | P 박스 | 28 | 1150×1150 |
| DIC(수출) | 종이박스 | 30 | 1100×1100 |
| KEFFICO SBW | P 박스 | 60 | 1100×1100 |
| MPS 내수 | P 박스 | 96 | 1100×1100 |
| MPS(수출) | 종이박스 | 15 | 1100×910 |
| 7AM DCT | P 박스 | 130 | 1200×1000 |
| TMED2 | P 박스 | 낱개 | — |
| CN7 | P 박스 | 40 | 1100×1100 |
| GEN1 | P 박스 | 낱개 | — |
| IMEB3 | P 박스 | 30 | 1100×1100 |
| D45 | P 박스 | 100 | 1100×900 (나무) |
| PURGE PUMP | P 박스 | 60 | 1100×1100 |
| EC PUMP | P 박스 (접이식) | 낱개 | — |
| PE | 단프라 | 24 | 1100×1100 |
| BATT | 단프라 | 24 | 1100×1100 |
| 조이슨 | P 박스 | 30 | 1100×1100 |
| 조이슨(수출) | 종이박스 | 30 | 1100×900 |

품명·품번에 제품군 이름이 들어 있으면 이 표를 씁니다.  
수출/CE는 수출 행을 먼저 봅니다. 예: `SBW ROTOR ASSY (CE)` → DIC(수출) 30박스/PLT.  
`HFP3.2 ROTOR` 등은 **3.2 ROTOR**(60)로 붙습니다.

제품별 **BOX별 중량(g)·PLT 무게**는 `당사 제품 출고 기준.xlsx` 제품 정리 시트를 따릅니다.  
표에 없거나 이름이 안 맞으면 박스만 표시하고 PLT는 비울 수 있습니다.

---

## 6. 지역

수도권은 2호차, 지방은 1호차를 기본으로 둡니다.  
충청 일부(음성, 충주, 청주, 서산, 예산 등)도 지금은 수도권으로 넣어 두었습니다. **잠정**입니다.

**설정 → 지역**에서 위치 이름을 추가·수정할 수 있습니다.

---

## 7. 설명에 넣을 말

아래 항목은 현재 프로토타입의 한계·운영 전 확인 사항입니다.

- **합차 되나요?** — **됩니다.** 보드에서 2건 이상 체크 후 **합차**. 카드에 `합차 XXXX` 뱃지. **묶음 해제**로 풀 수 있습니다. (BMC+코아 등 **강제 1set 자동 묶음**은 아직 없음)
- **모든 품목이 PLT로 나오나요?** — 제품 정리 표에 있는 것만 됩니다. 홈에서는 품명을 넣어야 환산됩니다.
- **파렛트 크기(1100×1000 등)로 차를 고르나요?** — 아닙니다. 박스→PLT 개수만 씁니다. 차 한도는 PLT 대수입니다.
- **중량은?** — BOX별 중량(g)×박스 수 또는 시트 PLT 무게를 씁니다. 미매칭 시 잠정 600kg/PLT입니다.

## 8. 실행 (개발·담당자)

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 을 엽니다.

처음 데이터(차량·지역)를 다시 심으려면 `npm run db:seed` 입니다. **일정까지 지워질 수 있으니** 이미 쓰고 있으면 실행하지 않습니다.

프로젝트 종료 후 운영 담당자, 백업·복구 방법, 장애 대응 절차가 정해지지 않았다면 실제 업무의 유일한 시스템으로 사용하지 않습니다.
