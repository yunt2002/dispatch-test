# Dispatch System

네오마그네틱 일일 배차 업무의 방향과 효과를 확인하기 위한 프로토타입입니다. 현재 방식으로 실제 운영 시스템을 구축하는 것은 아직 확정되지 않았습니다.

문서는 **[docs/](./docs/)** 에 모아 두었습니다.

- [docs/기획서.md](./docs/기획서.md) — 현재 가설 / 프로토타입 범위 / 운영 전제
- [docs/사용설명서.md](./docs/사용설명서.md) — 구현된 기능 확인 방법
- [docs/미팅정리.md](./docs/미팅정리.md) — 방향·기간·미팅 질문
